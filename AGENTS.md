# Working on SureFrame

Read [HANDOVER.md](HANDOVER.md) before changing anything. It has the ground rules (never wipe production data, additive-only migrations, never rename `framecast` identifiers, end-to-end encryption, production deploys only with the owner's go-ahead), the code map, how to run the tests, and how to publish and roll back.

The owner is not a developer: explain changes in plain language and ask before anything that can't be undone.
